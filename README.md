Designed and developed an interactive Tic-Tac-Toe web game using HTML, CSS, and JavaScript.

Created a 3×3 game board with responsive and visually appealing design.

Implemented Player vs Player and Player vs AI game modes.

Added logic to handle user clicks, update the game board, and switch turns.

Implemented win, draw, and game-over detection using predefined winning patterns.

Developed a basic AI opponent that can block, win, or make random moves.

Added score tracking for Player X, Player O, and draws.

Included a reset game feature to restart gameplay.
